# AI / ML 候选发现

发现最多5项值得进一步深读的问题，不为每项先写完整长稿，不凑数。优先近两周，必要时回看六周但明确日期和为什么现在仍重要。AI高优先但不排他，不要求每天模型发布。

轮换学习算法、模型架构、推理规划、训练/推理效率、数据与评测、可解释性、安全可靠性、机器人。接受NeurIPS、ICML、ICLR、ACL/EMNLP、CVPR等会议论文、严肃研究组或公司技术报告、arXiv；声誉与榜单不是证据。至少考虑一项非LLM或非大公司方向。

候选概述只写已读范围支持的问题与线索，指出最需要复核的实验、对照与失败条件。记录DOI/论文版次和原始URL；同一论文的摘要页、PDF和新版本是一条研究线索，不算多项。发布日期自己核对，元数据只用于发现，不冒充全文。历史重复需有具体新增事实；观察清单项目无进展则不占位。
